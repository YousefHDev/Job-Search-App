# 📌 Overview

A full-featured backend application for a modern Job Search Platform that allows users to search and apply for jobs, companies to manage job opportunities, and admins to monitor the platform.

The project follows a modular clean architecture with scalable API design, authentication systems, real-time communication, and security best practices.

# 🚀 Installation

## 1️⃣ Clone Repository

```bash id="x2og8y"
git clone https://github.com/your-username/job-search-app.git
```

---

## 2️⃣ Install Dependencies

```bash id="9t6r6g"
npm install
```

---

## 3️⃣ Configure Environment Variables

Create `.env` file:

```env id="j04hkj"
PORT=
MONGO_URI=
JWT_SECRET=
EMAIL=
PASSWORD=
```

---

## 4️⃣ Run Development Server

```bash id="m4st7i"
npm run dev
```
